# Why can't I deploy apps after exceeding my memory limit?
{: #noruntimemem}
{: troubleshoot}

You can't deploy apps in {{site.data.keyword.cloud_notm}} because your organization exceeded its runtime memory limit. Upgrade your Lite account or delete apps to free memory.
{: shortdesc}

You're unable to deploy apps, and an error states that you've exceeded your organization's memory limit.
{: tsSymptoms}

For Pay-As-You-Go or Subscription accounts, there's a 2 GB memory limit.
{: tsCauses}

You can get more memory by upgrading your Lite account. Go to **Manage** > **Account** in the {{site.data.keyword.cloud_notm}} console, and select **Account settings**. For more information about Lite account features, see [Lite account](/docs/account?topic=account-accounts-types#liteaccount).
{: tsResolve}

If you don't want to upgrade from a Lite account but have some idle apps, you can delete them to free up some runtime memory.
